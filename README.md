# 🍕 Pizza Sales Analysis — Excel Dashboard

## 📌 Project Overview

This project analyzes **pizza sales data for 2025** using Microsoft Excel to identify sales trends, customer ordering patterns, product performance, and revenue contribution.

The project includes an interactive Excel dashboard supported by KPI analysis, daily and hourly order trends, pizza category and size analysis, and best/worst-selling pizza identification.

---

## 🎯 Objectives

* Analyze overall pizza sales performance.
* Track key business KPIs such as revenue, orders, and pizzas sold.
* Identify daily and hourly ordering trends.
* Analyze sales contribution by pizza category and size.
* Identify the best- and worst-selling pizza products.
* Build an Excel dashboard to present insights visually.

---

## 📊 Dataset

The dataset contains **48,620 pizza sales records** with information about individual pizza orders.

### Key Columns

| Column              | Description                             |
| ------------------- | --------------------------------------- |
| `pizza_id`          | Unique identifier for each pizza record |
| `order_id`          | Identifier for the customer order       |
| `pizza_name_id`     | Unique pizza product identifier         |
| `quantity`          | Number of pizzas ordered                |
| `order_date`        | Date of the order                       |
| `order_day`         | Day of the week                         |
| `order_time`        | Time of the order                       |
| `unit_price`        | Price of one pizza                      |
| `total_price`       | Total revenue generated                 |
| `pizza_size`        | Size of the pizza                       |
| `pizza_category`    | Pizza category                          |
| `pizza_ingredients` | Ingredients used                        |
| `pizza_name`        | Name of the pizza                       |

## 📅 Sales Trend Analysis

### Daily Order Trend

The analysis shows the number of orders across each day of the week.

| Day       | Orders |
| --------- | -----: |
| Sunday    |  2,624 |
| Monday    |  2,794 |
| Tuesday   |  2,973 |
| Wednesday |  3,024 |
| Thursday  |  3,239 |
| Friday    |  3,538 |
| Saturday  |  3,158 |

**Friday recorded the highest number of orders**, while Sunday had the lowest.

### Hourly Order Trend

The analysis also examines order volume throughout the day.

Peak ordering activity occurs primarily around the **lunch and evening periods**, with the highest hourly order volume occurring around **12 PM**.
